# LEARNELIO

Mini-site responsive de vente de formations.

## Fonctionne déjà
- Accueil responsive
- Catalogue de 3 formations
- Pages formation dynamiques
- Parcours vers une page commande
- Contact et page légale provisoire

## Avant vente réelle
1. Vérifier/réserver la marque et les domaines.
2. Connecter Stripe (ou autre PSP) : aucune carte n’est encaissée dans cette version.
3. Créer un espace membre/LMS et la livraison automatique des contenus.
4. Configurer l’e-mail professionnel.
5. Faire compléter/valider les mentions légales, CGV, confidentialité et règles de rétractation selon l’entreprise et l’offre réelles.
6. Déployer chez un hébergeur.
